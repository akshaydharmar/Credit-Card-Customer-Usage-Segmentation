Credit Card Customer Usage Segmentation

Developed a customer segmentation system for credit card users using data analysis and unsupervised machine learning. The project analyzes customer spending patterns, transaction behavior, payment habits, and credit usage to identify distinct customer segments. Using Python, Pandas, Matplotlib, Seaborn, and K-Means Clustering, customers are grouped into meaningful categories that can help businesses understand customer behavior, personalize marketing strategies, improve customer retention, and identify high-value customer groups.

Tech Stack: Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • K-Means Clustering
